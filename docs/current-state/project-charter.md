# Project charter

## Historical purpose

The repository preserves the idea of modernizing an institutional air-traffic-control portal based on earlier professional experience and legacy work.

## Verified current scope

- Laravel 10 framework structure and standard application configuration.
- Vue/Vite frontend entry assets and a themed welcome page.
- User model, database migrations, Passport dependencies, and simple authentication-related API routes.
- Docker, Nginx, Swagger/L5-Swagger, PHPUnit, and Tailwind project assets.

## Not currently implemented

- Control tower, radar approach, flight-data, airspace, incident, reporting, or charting modules.
- Verified role-based authorization, data mocking, operational dashboard, and real-time workflows.
- A complete domain data model, production deployment, or evidence of an aviation system.

## Portfolio decision

Classify the repository as a learning/archive candidate, not a personal-profile showcase. It may become a future Laravel modernization project only with a new, scoped implementation plan.
