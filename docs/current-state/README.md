## Status

The codebase is a Laravel 10 application starter with Vue/Vite assets, Passport-oriented authentication routes, tests inherited from the framework scaffold, Docker assets, and a themed landing page. The air-traffic-control domain modules described in older documentation are not implemented in the current source tree.

It should not be featured as a finished airspace-control application. Retain it only as an archived Laravel learning/reference project unless a future implementation program is approved.
