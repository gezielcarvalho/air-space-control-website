# Delivery and quality

## Maturity

This is an archived learning/reference application rather than a release candidate. Framework scaffolding and authentication-oriented routes do not amount to a verified operational portal.

## Before any revival

1. Create a domain-led product brief and define a safe non-operational demonstration boundary.
2. Implement the domain model and modules with explicit test coverage.
3. Review authentication, Passport use, configuration, secrets handling, and dependency lifecycle.
4. Establish CI, database strategy, observability, deployment, and security controls.
5. Do not make air-traffic operational, safety, real-time, or regulatory claims without specialist validation.

## Documentation-only validation

Validate Markdown links and whitespace/diff checks. No route, configuration, dependency, or runtime behavior changes are included.
